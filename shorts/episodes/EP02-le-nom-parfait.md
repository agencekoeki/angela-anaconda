# Ép. 2 · Le nom parfait

**L'idée de départ** (Sébastien, 30/10/2026) : un des premiers concepts de la saison, ce sont les EMD, racontés par l'histoire vraie du Pull Moche, la boutique de Sébastien et Diana (lepullmoche.shop) ; Diana et Kristina expliquent, avec tendresse ; le site lepullmoche.com a disparu dans l'incendie de l'hébergeur, avec sa sauvegarde, qui était au même endroit (« LOL »). Cet épisode prend la place 2 de la saison ; « Personne ne me cite » et les suivants passent d'un rang (`shorts/saison-1.md`).

**La question** (posée à la première seconde) : Kristina sort un pull moche d'un carton : « C'est quoi, ce truc ? » — « Notre meilleur nom de domaine. » Comment un pull peut-il être un nom de domaine, et est-ce le nom qui a fait le succès ?

**Le test des trois phrases**
1. Le jour de la Journée du pull moche 2016, Sébastien achète lepullmoche.shop, persuadé que le nom suffira à être premier sur Google.
2. Rien ne bouge (page 9, puis pire) ; Diana prend la main, remplit le site de vrais pulls moches drôles, puis dessine le leur : ça décolle.
3. Aujourd'hui, Tara montre que les clics venaient de « pull de noel », qui n'est même pas dans le nom ; et le .com, lui, a brûlé avec sa sauvegarde.

**La pépite**, dite par Kristina : « Un nom ne classe pas un site. C'est dedans qui compte. » Le bandeau : « EMD : le nom = le mot-clé · Pour Google, un mot-clé dans le nom n'a « presque aucun effet ». Il juge ce qu'il y a dedans. »
- [SAVOIR : Google Search Central, SEO Starter Guide, mis à jour le 10/12/2025] Les mots-clés dans le nom de domaine ou l'URL n'ont « presque aucun effet » au-delà de leur affichage : la citation du bandeau vient de là.
- [SAVOIR : Search Engine Roundtable, 29/09/2012 ; Search Engine Land] Le 28/09/2012, Google annonce une mise à jour qui « réduit les domaines exact-match de faible qualité » (0,6 % des requêtes en anglais des États-Unis) ; dès mars 2011, Matt Cutts disait « baisser le bouton » du poids des mots-clés dans les domaines.
- [SAVOIR : Search Engine Journal, 16/02/2022] John Mueller : aucun bonus SEO, ni secret ni public, pour les mots-clés dans le domaine.
- Correction après relecture : la première version du bandeau disait « Depuis 2012, Google ne donne plus de bonus au nom ». C'était dater et durcir une position formulée plus tard (2012 visait les EMD *de faible qualité* ; le « pas de bonus » est de 2022 ; Google dit « presque aucun », pas « aucun »). Le bandeau cite maintenant Google mot pour mot.

**Ce que montrent les chiffres du site** (et ce qu'ils ne montrent pas) :
- [SAVOIR : capture `7-google analytics lepullmoche search consol query.jpg`, du 01/10/2020 au 23/01/2021] « pull de noel » : 44 518 clics, position moyenne 3,1 ; « pull moche » (la requête du nom) : 3 942 clics, position 1,1. La requête absente du nom a rapporté onze fois plus de clics.
- [PENSER] Ces chiffres montrent d'où venaient les clics ; ils ne mesurent pas l'effet du nom sur le classement (« pull moche » était bien premier). C'est pourquoi Tara ne dit plus « presque rien » : elle dit « Regarde », et l'écran montre les chiffres ; la pépite, elle, s'appuie sur ce que dit Google.
