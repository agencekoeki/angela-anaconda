# Angela Anaconda — Base de connaissances

## 1. Ce que contient la base

Des fichiers Markdown en français sur la série animée *Angela Anaconda* : 65 épisodes de deux segments d'une dizaine de minutes, soit 130 histoires, diffusés de 1999 à 2001, avec Sue Rose dans le rôle-titre.

| Dossier | Contenu | État |
|---|---|---|
| `episodes/` | Un découpage scène par scène par épisode, ses deux segments compris | 1 sur 65 (S1E01) |
| `personnages/` | Une fiche par personnage : apparence, expressions, bouche, gestes, tenues | Angela, commencée |
| `_methode/` | La méthode de visionnage et la carte de couverture de la chaîne YouTube officielle | Faites ; la carte est à confirmer à l'image |

Les fiches thématiques (production, voix, Tapwater Springs, running gags, réception) viendront quand assez d'épisodes auront été regardés pour les nourrir.

## 2. La règle d'or

**Aucun dialogue n'est recopié.** L'action est racontée avec nos mots : le lieu, les personnages, ce qui se passe, ce qu'on voit, ce que ça veut dire. Chaque découpage renvoie à la vidéo officielle, à la minute près, pour qui veut voir la scène.

## 3. Les étiquettes

| Étiquette | Sens |
|---|---|
| `[VU À L'IMAGE]` + minutage | Constaté sur une image de la vidéo officielle |
| `[TRANSCRIPTION AUTO]` + minutage | Déduit de ce qui est dit, d'après la transcription automatique de YouTube (jamais citée) |
| `[INTERPRÉTATION]` | Lecture du rédacteur |
| `[À VÉRIFIER]` | Point douteux |

Les titres, la numérotation et les dates de diffusion suivent la [liste des épisodes de Wikipédia](https://en.wikipedia.org/wiki/List_of_Angela_Anaconda_episodes), relevée le 2026-10-29. C'est une source secondaire, à recouper.

## 5. Mode d'emploi pour une IA

- Commencer par ce fichier, puis `_methode/visionnage.md` pour savoir ce que valent les étiquettes.
- Un fait sans étiquette `[VU À L'IMAGE]` n'a pas été constaté sur l'image.
- Les minutages renvoient à la vidéo citée dans l'en-tête du découpage, pas à l'épisode : la chaîne publie des compilations.
- Ne pas compléter un trou par un souvenir. Un segment non regardé est marqué « à faire », pas résumé.
